# Sabrina Siu Design Skill

A Codex skill for designing portfolio pages in the visual language of [sabrinasiu.com](https://www.sabrinasiu.com/). It captures the site's editorial typography, violet accents, spacious layouts, media presentation, and restrained motion while leaving room to adapt those choices to new content.

## Use it

Install the repository in your Codex skills folder:

```sh
git clone https://github.com/sabrinasiu/sabrina-siu-design.git ~/.codex/skills/sabrina-siu-design
```

Then ask Codex, for example:

> Use $sabrina-siu-design to design a portfolio page for my new project.

The instructions are in [SKILL.md](SKILL.md). The skill is meant for work that should match or extend this site's style, not for unrelated designs.

## Reference

The skill is based on the public [home](https://www.sabrinasiu.com/), [personal](https://www.sabrinasiu.com/personal.html), and [work entrance](https://www.sabrinasiu.com/portfolio.php) pages. The password-protected work pages were not inspected.
